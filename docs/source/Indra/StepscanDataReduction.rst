Reduce step scan data
=====================

When you collect step scan USAXS data, the data are saved inside a spec file.
The spec file name is formed by prepending the month and day (``MM_DD_``) to
the name provided by staff, typically derived from the user name. For SAXS
data, a folder with the same base name and the suffix ``_saxs`` is created;
for WAXS data, the suffix ``_waxs`` is used.

After reducing data from the USAXS instrument, the Igor experiment organizes
data into folders. USAXS data are stored under ``root:USAXS:Samplename``.
To browse the current Igor experiment, use the Data Browser (Ctrl-B or Cmd-B).
